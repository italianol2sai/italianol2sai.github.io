✏️ IL PARTICIPIO PASSATO

-ARE → -ATO-ERE → -UTO-IRE → -ITO
MANGIARE → MANGIATOAVERE → AVUTODORMIRE → DORMITO
LAVORARE → LAVORATORICEVERE → RICEVUTOCAPIRE → CAPITO
ANDARE → ANDATOVENDERE → VENDUTOPARTIRE → PARTITO
ATTENZIONE: MOLTI VERBI IN -ERE SONO IRREGOLARI!
